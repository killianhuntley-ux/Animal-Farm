# 06 — Weaving

**Question this slice answers:** *Does the two-door decision (Ascend vs Weave) create genuine deliberation — and does making your first cryptid feel like a discovery, not a menu?*
**GDD:** §2.7 (weaving rules — all locked), §2.2 (door 2), §6.1 (two-door tuning risk)

---

## Builds (systems)

- **Weave ritual flow:** select two residents **both at MAX Spirit** (locked gate, GDD §2.7) → ritual site → consent beat ("they've both signed the waiver") → ceremony → both parents consumed → the woven spirit emerges.
- **Recipe system (data):** authored pair → result table. Deterministic once discovered. **Journal shows undiscovered weaves as silhouette entries only** — never recipes (locked, GDD §2.7). Silhouette *hints* (shape suggests the parents) are the discovery breadcrumb.
- **Invalid pairing = gentle fizzle:** morale dip + an authored joke line, nothing lost (GDD §1.7). Fizzles log the attempted pair in the journal so experimentation isn't punished by forgetting.
- **Portmanteau auto-naming:** the weave's default name splices the parents' *player-given* names (GDD §2.7); player may override.
- **Trait inheritance:** one trait from each parent (competition stat leanings, activity window, a need). Keep it two slots — visible, explainable.
- **One generation only:** weaves cannot re-weave (locked; enforce in data).
- **Weaves in the lifecycle:** a woven cryptid is a resident like any other — can compete, fulfil, and **Ascend for a larger legacy** (this is what makes door-2 not a dead end; tune here).

## Content

- **2 woven cryptid species** (the folklore trick, GDD §2.7): e.g. rabbit-spirit + deer-spirit → **jackalope-class cryptid**; night-spirit + bird-spirit → second cryptid. New rigs/skins (cryptids deserve bespoke silhouettes — they're the reward tier).
- Ritual site greybox on the Prairie, ceremony VFX/SFX placeholder, ~6 fizzle joke lines.
- Journal: Weaves tab with silhouettes; Legacy Gallery handles ascended weaves with a distinct marker.

## Out of scope

The full ~15–20 cryptid roster, ritual-currency question (essence-as-weave-cost is deferred, GDD §6.3 — weaving is free-but-gated for now), DLC chain-weaving.

## Depends on

04 (max-Spirit, ascension, legacies), 03 (residents), 05 (traits need competitions to matter).

## Definition of Done

- [ ] First weave discovery happens through *play* (silhouette hint → hunch → attempt), not through reading
- [ ] Consuming two named, maxed spirits produces real hesitation — and the result justifies it
- [ ] Testers split roughly rather than unanimously between Ascend and Weave for a given maxed pair (the two-door tension is alive — GDD §6.1; if one door is ignored, tune legacy value vs cryptid value before proceeding)
- [ ] Fizzle raises a laugh, not a reload
- [ ] The portmanteau name moment lands (testers say the name out loud)
- [ ] New recipe = data only; new cryptid = data + rig/skin
- [ ] Save-safe at every step, mid-ritual included

## Risks

- **Door imbalance is the named design risk (GDD §6.1)** — this slice exists partly to surface it early with real testers.
- Cryptid art is the first *bespoke-quality* art demand; coordinate friend-artist lead time now (GDD §6.2 — never block code on final art; greybox cryptids are acceptable to test with).
